## Protocol

CSPR.AI implements the [Model Context Protocol (MCP)](https://modelcontextprotocol.io) specification.

### Request Format

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "tool_name",
    "arguments": {
      "param1": "value1"
    }
  }
}
```

### Response Format

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Result content"
      }
    ]
  }
}
```

## Available Methods

### Tools

| Method | Description |
|--------|-------------|
| `tools/list` | List available tools |
| `tools/call` | Execute a tool |

### Resources

| Method | Description |
|--------|-------------|
| `resources/list` | List available resources |
| `resources/read` | Read a resource |

## Authentication

<Callout>
  The MCP server does not require authentication by default. For production deployments, implement authentication at the infrastructure level.
</Callout>

## Rate Limiting

Default rate limits:

| Endpoint | Limit |
|----------|-------|
| Read operations | 100 req/min |
| Write operations | 20 req/min |

## Error Handling

All errors follow the MCP error format:

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32000,
    "message": "Error description",
    "data": {
      "details": "Additional information"
    }
  }
}
```

See [Error Codes](/api-reference/error-codes) for complete list.

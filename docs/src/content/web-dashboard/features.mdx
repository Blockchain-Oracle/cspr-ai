# Dashboard Features

The CSPR.AI web dashboard provides a visual interface for blockchain interaction.

## AI Chat Interface

Interact with the blockchain using natural language:

- **Balance Queries** - "What's my CSPR balance?"
- **Validator Info** - "Show me the top validators"
- **Transaction Building** - "Transfer 100 CSPR to..."
- **Contract Interaction** - "Mint an NFT to..."

### Chat Features

- Markdown rendering for responses
- Code syntax highlighting
- Transaction previews
- Error explanations

## Portfolio View

See your complete portfolio at a glance:

- **CSPR Balance** - Native token balance
- **Token Holdings** - CEP-18 tokens
- **NFT Collections** - Owned NFTs
- **Staking Info** - Delegations and rewards

## Transaction History

View and track transactions:

- **Pending** - Waiting for confirmation
- **Success** - Completed transactions
- **Failed** - With error details
- **Filters** - By type, date, status

## Network Switcher

Easily switch between networks:

| Network | Use Case |
|---------|----------|
| Testnet | Development, testing |
| Mainnet | Production transactions |

<Callout type="warning">
  Always verify you're on the correct network before signing transactions.
</Callout>

## Transaction Builder

Visual transaction creation:

1. **Select Type** - Transfer, delegate, contract call
2. **Enter Details** - Recipient, amount, parameters
3. **Review** - Check transaction details
4. **Sign** - Approve with CSPR.click
5. **Track** - Monitor status

## Validator Explorer

Research validators for staking:

- **Stake Rankings** - Sorted by total stake
- **Delegation Rates** - Fee comparison
- **Performance** - Block production history
- **Quick Delegate** - One-click delegation

## Token Operations

Manage CEP-18 tokens:

- View token balances
- Transfer tokens
- Check approvals
- Transaction history

## NFT Gallery

Browse and manage NFTs:

- Collection overview
- Individual token details
- Transfer NFTs
- View metadata

## Settings

Customize your experience:

- **Theme** - Light/dark mode
- **Network** - Testnet/mainnet
- **Display** - Currency formatting
- **Notifications** - Transaction alerts

## Responsive Design

The dashboard works on:

- Desktop browsers
- Tablets
- Mobile devices (limited features)

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open command palette |
| `Ctrl/Cmd + /` | Focus chat |
| `Esc` | Close modals |

## Accessibility

The dashboard follows WCAG guidelines:

- Keyboard navigation
- Screen reader support
- High contrast mode
- Focus indicators

## Tool Types

### Read-Only Tools

Read-only tools query the blockchain without making changes:

- `casper_get_balance` - Query account balance
- `casper_get_validators` - List validators
- `casper_get_deploy_status` - Check transaction status

<Callout>
  Read-only tools are free to use and don't require a wallet.
</Callout>

### Transaction Builders

Transaction builders create unsigned transactions that must be signed:

- `casper_build_transfer` - Build CSPR transfer
- `casper_build_delegation` - Build stake delegation
- `casper_build_token_transfer` - Build token transfer

<Callout type="warning">
  Transaction builders return unsigned transactions. You must sign them with your wallet before submitting.
</Callout>

### Signing Tools

If configured with a secret key, the server can sign and submit:

- `casper_sign_and_submit_transaction` - Sign and submit to network
- `casper_wallet_status` - Check wallet configuration

## Using Tools with Claude

When chatting with Claude, simply describe what you want to do:

```
What's the balance of account 01abc...?
```

Claude will automatically select the appropriate tool and execute it.

For complex operations, Claude will guide you through the steps:

1. Query current state
2. Build transaction
3. Present for signing
4. Track execution status

## Error Handling

All tools return structured error messages:

```json
{
  "error": "Invalid public key format",
  "details": "Public key must start with 01 (Ed25519) or 02 (Secp256k1)"
}
```

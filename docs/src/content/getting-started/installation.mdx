# Installation

This guide covers various installation methods for CSPR.AI.

## Requirements

| Requirement | Version | Notes |
|------------|---------|-------|
| Node.js | 18+ | LTS recommended |
| pnpm | 8+ | `npm install -g pnpm` |
| Git | Latest | For cloning |

## Installation Methods

<Tabs items={['From Source', 'Docker', 'npm (Coming Soon)']}>
  <Tabs.Tab>
    ### Clone and Install

    ```bash
    # Clone the repository
    git clone https://github.com/Blockchain-Oracle/cspr-ai.git
    cd cspr-ai

    # Install MCP server dependencies
    cd mcp-server
    pnpm install

    # Build for production
    pnpm build
    ```

    ### Project Structure

    ```
    casper-mcp/
    ├── mcp-server/        # MCP server (TypeScript)
    │   ├── src/
    │   │   ├── tools/     # MCP tool definitions
    │   │   ├── utils/     # Utility functions
    │   │   └── index.ts   # Entry point
    │   └── package.json
    ├── contracts/         # Smart contracts (Rust/Odra)
    │   ├── cep18/         # Token contract
    │   ├── nft/           # NFT contract
    │   ├── dao/           # DAO contract
    │   └── dex/           # DEX contract
    ├── web/               # Web dashboard (React)
    └── docs/              # Documentation (Nextra)
    ```
  </Tabs.Tab>

  <Tabs.Tab>
    ### Using Docker

    ```bash
    # Build the image
    docker build -t cspr-ai-mcp ./mcp-server

    # Run the container
    docker run -d \
      -p 3001:3001 \
      -e CASPER_NETWORK=testnet \
      -e MCP_TRANSPORT=http \
      -e CSPR_CLOUD_API_KEY=your-api-key \
      cspr-ai-mcp
    ```

    ### Docker Compose

    ```yaml filename="docker-compose.yml"
    version: '3.8'
    services:
      mcp-server:
        build: ./mcp-server
        ports:
          - "3001:3001"
        environment:
          - CASPER_NETWORK=testnet
          - MCP_TRANSPORT=http
          - CSPR_CLOUD_API_KEY=your-api-key
        restart: unless-stopped
    ```
  </Tabs.Tab>

## Verifying Installation

After installation, verify everything is working:

```bash
# Check the MCP server starts
cd mcp-server
pnpm dev

# You should see:
# MCP Server started on stdio transport
# or (with MCP_TRANSPORT=http)
# MCP Server started on HTTP transport at http://localhost:3001
```

## Installing Smart Contract Tools

If you plan to work with smart contracts:

```bash
# Install Rust (if not already installed)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Add wasm32 target
rustup target add wasm32-unknown-unknown

# Install cargo-odra
cargo install cargo-odra

# Verify installation
cd contracts
cargo odra build
```

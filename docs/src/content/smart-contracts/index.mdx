## Prerequisites

Before working with contracts, install:

```bash
# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Add wasm32 target
rustup target add wasm32-unknown-unknown

# Install cargo-odra
cargo install cargo-odra
```

## Building Contracts

```bash
cd contracts

# Build all contracts
cargo odra build

# Build specific contract
cargo odra build -c cep18
```

## Testing

<Callout type="info">
  Always test with both OdraVM (fast) and CasperVM (accurate) before deployment.
</Callout>

```bash
# Fast iteration with OdraVM
cargo odra test

# Accurate validation with CasperVM
cargo odra test -b casper
```

## Deployment

Contracts are deployed using the MCP tools:

1. Build the contract WASM
2. Use AI to deploy with appropriate parameters
3. Track deployment status
4. Save contract address for future use

## Security Considerations

All contracts follow security best practices:

- **Access Control**: Using Odra's `Ownable` module
- **Input Validation**: All entry points validate inputs
- **Events**: State changes emit events for tracking
- **No Private Keys**: MCP tools never handle private keys
